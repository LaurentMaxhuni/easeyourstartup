# Outfit web font assets

These are the unchanged variable-font subset files emitted by this checkout's Next.js `next/font/google` loader for `Outfit({ subsets: ["latin"] })`. The generated CSS identifies both files as Outfit, normal style, weight range 100–900, with separate Latin and Latin-Ext glyph subsets.

- `outfit-latin.woff2` — SHA-256 `92684e4acde79ef07758cd09380b7e01e9824d8b061eddeda046f78c166d7b12`
- `outfit-latin-ext.woff2` — SHA-256 `9e38b3f1575daba3435ef09d33a202585ed5bd204bd0a8c744955c750c2b9091`

Upstream family metadata: [Google Fonts Outfit](https://github.com/google/fonts/tree/main/ofl/outfit). The metadata identifies Outfit as a variable font (100–900), licensed under the SIL Open Font License, and names [Outfitio/Outfit-Fonts](https://github.com/Outfitio/Outfit-Fonts) as the source repository. The Google Fonts metadata currently records source commit `902773808eb372f70fb34e8946dd1ffe604efc79`; Next's generated cache did not record the exact upstream revision for these subset files. The full upstream license and copyright notice are in [OFL.txt](./OFL.txt).

The font binaries were copied from the ignored `.next/dev/static/media` output into this tracked source directory so builds no longer depend on that cache or fetch Google Fonts. Their hashes are recorded above to identify these exact copies.
